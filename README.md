## 🚀 Quick Start

### Option 1: Local HTTP Server (Recommended)

1. Run the local dev server:
   ```bash
   npm run dev
   # or
   npm start
   # or
   node server.js
   ```

2. Open your browser at:
   ```
   http://localhost:8080/
   ```

> **Server Features:** Built with zero external dependencies. Features HTTP Range request support (`206 Partial Content`) for instant media streaming (ambient nature sounds), automated port collision fallback, and local mock API endpoints for B2B inquiry handling.

### Option 2: Direct File Protocol (`file:///`)

You can double-click or open `index.html` directly in any web browser. Primary fonts are embedded as Base64 data URIs to guarantee crisp rendering under local file restrictions.

## 📱 Mobile-Friendly & Interactive Features

- **Touch Swipe Gestures:** Native swipe left/right across bottle sliders on smartphones and tablets.
- **Dynamic Water Loader:** Animated vector wave filling the **WATER, WITH A REASON.** logo from 0% to 100%.
- **LocomotiveScroll Parallax:** 3D geological strata, nature soundscapes, and floating leaf dynamics.
- **Sticky B2B Quick Actions:** Floating mobile action bar for one-tap calling (`+91 (079) 2658-WATER`) and tasting kit requests.
- **Zero Third-Party Trackers:** Purged of external tracking scripts (Facebook Pixel, GTM, Matomo) for 0 console errors and 100% privacy compliance.
